# SearchApi travel planning skill

Compare hotel prices and door-to-door transit, or check flight dates, baggage, and booking options.

Copy this folder into your agent's skills directory. Connect [SearchApi](https://www.searchapi.io) or set `SEARCHAPI_API_KEY` for the REST examples. See [SKILL.md](SKILL.md) and the [documentation](https://www.searchapi.io/docs) for setup and available engines.

A helper skill for [a blog post about travel planning](https://eamag.me/2026/ai-travel-planning).
